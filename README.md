# pokedex

Mini CLI pokemon catching game written in go.

# Quick start

```console
$ go run .
```
This should be the output

```console
Pokedex > 
```

# Usage
```console
Pokedex > help

Usage:

exit: Exit the Pokedex
map: Gets next 20 map elements
mapb: Gets previous 20 map elements
catch: Tries to catch the pokemon
inspect: Inspects caught pokemon
pokedex: Shows list of caught pokemons
explore: Explores a given location
help: Displays a help message
```
